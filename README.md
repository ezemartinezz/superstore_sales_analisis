# Análisis de Ventas - Superstore Dataset
## Descripción
Análisis exploratorio de un dataset de ventas de una cadena de supermercados de Estados Unidos, utilizando Google Sheets.
## Herramientas utilizadas

Google Sheets

## Dataset

Fuente: Kaggle - Superstore Dataset
9994 registros y 21 columnas
Período: 2014 - 2017

## Análisis realizado

Métricas descriptivas generales
Ventas y rentabilidad por categoría
Ventas y rentabilidad por región
Evolución de ventas por año

## Conclusiones principales

Technology es la categoría más rentable con un margen del 17,40%
Furniture presenta un margen crítico del 2,49% a pesar de alto volumen de ventas
La región West lidera en ventas y ganancias
Las ventas crecieron un 65,33% en 2016 respecto al año anterior
